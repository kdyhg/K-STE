# K-STE

한국어 작업 지시문에서 **필요한 영역만** 명확하게 다듬는 AI 스킬입니다.

일반 대화나 전체 프롬프트에는 규칙을 강제하지 않습니다. 사용자가 지정한 작업 요구사항, 제약 조건 또는 결과물 형식에만 적용합니다.

## 특징

- **기본 비활성:** 사용자가 명확화를 요청하지 않은 경우 원문 유지
- **부분 적용:** 요청된 영역만 분석 및 수정
- **의미 보존:** 사실, 수치, 필수/권장/선택 강도, 조건, 예외와 금지 사항 보존
- **가정 금지:** 누락된 값을 임의로 채우지 않고 확인 필요 항목으로 표시
- **진단과 재작성 분리:** 자동 검사는 경고만 표시하며 임의 수정하지 않음
- **한국어 우선:** 지시 대상, 생략된 주어, 지시어, 모호한 부사, 조건의 적용 범위 등에 초점

## 사용 예시

```text
다음 개발 요청에서 '작업 요구사항'과 '변경 금지 조건'만 K-STE로 명확하게 고쳐줘.
다른 설명은 수정하지 마.
```

```text
이 문서의 결과물 형식만 K-STE로 점검해줘. 재작성하지 말고 위험한 표현만 알려줘.
```

```text
UI 설계는 자유롭게 두고, DB 변경 조건만 명확히 적어줘.
```

## 사용 방식

1. AI 스킬을 지원하는 환경에 이 저장소의 `SKILL.md`를 등록합니다.
2. 한국어 작업 지시와 함께 `K-STE` 및 적용 영역을 지정합니다.
3. AI는 지정된 영역만 수정하고, 나머지는 그대로 유지합니다.

### 검사기

Python 3.10 이상, 외부 패키지 없음.

```bash
python scripts/kste_lint.py instructions.md --scope requirements,constraints
python scripts/kste_lint.py instructions.md --scope output --format json
python scripts/kste_lint.py instructions.md --all
python -m unittest discover -s tests -v
```

영역 식별은 Markdown 제목 또는 명시적 구간 표식을 사용합니다.

```markdown
## 작업 요구사항
게시글의 첨부파일을 슬라이드 위에 표시한다.

## 제약 조건
기존 게시글 데이터는 삭제하지 않는다.
```

제목이 없는 문서에서는 다음 표식을 사용할 수 있습니다.

```text
<!-- kste:start scope=requirements -->
이거 적절하게 수정해줘.
<!-- kste:end -->
```

기본값은 **전체 문서 검사 금지**입니다. 영역이 없으면 검사기에서 오류 코드 2로 중단합니다. `--all`은 명시적인 전체 검사 요청에만 사용합니다.

## 파일

- `SKILL.md`: 선택 적용 정책과 재작성 절차
- `references/ko-rules.md`: 한국어 지시문 명확화 규칙
- `examples/usage.md`: 적용 예시
- `scripts/kste_lint.py`: 선택 영역 검사기
- `tests/`: 동작 검증

## 유의 사항

이 스킬은 프롬프트의 모호함을 줄이는 보조 도구입니다. AI의 성능 향상이나 결과의 정확성을 보증하지 않습니다. 검사기는 표면적인 신호만 찾으며, 의미 일치 여부는 사람이 확인해야 합니다.
